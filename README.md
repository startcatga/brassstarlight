# Brass & Starlight

A calm, offline constellation-tracing puzzle for Android. From a rooftop
observatory you find figures hidden among the stars, trace them with one
finger and seal them into your Star Atlas. There are 40 nights in four
chapters, a daily sky, seals to earn and lanterns for hints. No ads, no
purchases, no data collected.

- Flutter 3.47.9 · Dart 3.13 · Android only
- Package: `com.brassandstarlight.game`
- Design and plans: [docs/README.md](docs/README.md)

## Develop

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

Art, sounds and icons are generated by scripts (Python 3 + Pillow + numpy;
ffmpeg for the ambience loop):

```bash
python tool/make_art.py          # chapter skies, hub scene, paper
python tool/make_sfx.py          # every sound effect + night ambience
python tool/make_store_art.py    # logo, launcher/web icons, store art
dart run flutter_launcher_icons  # apply the launcher icon
```

## Release builds (GitHub Actions)

Release APKs and AABs are **never built locally**. Every push runs
`.github/workflows/android-release.yml`, which:

1. analyses and tests the game,
2. decodes the signing keystore from a GitHub Secret,
3. builds a signed release APK and AAB,
4. checks that neither is signed with the debug key,
5. deletes the keystore and `key.properties`, even if a step failed,
6. uploads the artifacts `brass-and-starlight-release-aab` and
   `brass-and-starlight-release-apk`.

Secrets are passed only through environment variables and are never echoed.

### One-time setup: keystore and secrets

1. Install a JDK (for `keytool`).
2. Generate the upload keystore. The script asks for **company details only**
   (publisher name, unit, organisation, city, state, country code), a key
   alias, a validity and two passwords:

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/generate_keystore.ps1
   ```

   or on macOS/Linux:

   ```bash
   bash scripts/generate_keystore.sh
   ```

   **Privacy:** the script does not read your username, machine name, IP
   address, location or any other system information, and it auto-fills
   nothing. The certificate contains only what you type.

3. It writes `scripts/starcart-upload.jks` and
   `scripts/starcart-keystore-base64.txt`. Both are git-ignored.
4. Add four repository secrets (GitHub → Settings → Secrets and variables →
   Actions), or with the GitHub CLI:

   ```bash
   gh secret set STARCART_KEYSTORE_BASE64 < scripts/starcart-keystore-base64.txt
   ```

   ```bash
   gh secret set STARCART_STORE_PASSWORD
   ```

   ```bash
   gh secret set STARCART_KEY_ALIAS
   ```

   ```bash
   gh secret set STARCART_KEY_PASSWORD
   ```

5. Push, or run the workflow from the Actions tab (`workflow_dispatch`).
   Download the AAB from the run's artifacts and upload it to Play Console.

**Back up the `.jks` file and both passwords offline, in two places.** If the
upload key is lost you need Play's key-reset process. Then delete the base64
text file.
